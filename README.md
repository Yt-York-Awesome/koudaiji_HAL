# 工业传送带物品检测系统（STM32F407 · HAL 版）

> 基于 STM32F407 与 STM32 HAL 库开发的智能物品检测与定位系统。
> 系统通过 AI 视觉识别模组检测传送带（或电视画面）上指定颜色与形状的物体，驱动二轴云台带动激光笔自动指向目标，并结合语音播报、红外遥控、双屏显示实现完整的"识别 → 定位 → 指示 → 记录"闭环。
> 当前版本：**V2.2.0**

## 项目简介

本项目为工业传送带物品检测系统的嵌入式实现，主控采用 STM32F407（Cortex-M4F，168MHz）。

系统工作流程：

1. AI 视觉识别模组实时检测画面中指定**颜色 + 形状**的物体，并上报物体坐标（最多 10 个）；
2. 主控通过**红外遥控**发送"OK/暂停"键，暂停作为动态画面源的电视机（消除运动模糊干扰识别）；
3. 连续多次确认目标稳定存在后，二轴云台带动**激光笔**依次指向每个目标；
4. **语音模块**播报检测结果，**迪文屏 / 板载 LCD** 同步显示物体颜色、形状、坐标与识别总数；
5. 全部目标指示完成后，红外恢复电视播放，进入下一轮检测；每次检测记录（时间、模式、颜色、形状、坐标）自动存入日志，最多 100 条，支持翻页回看。

检测对象为 4 种颜色 × 5 种形状共 20 种组合：

| 颜色 | 红、绿、蓝、黄 |
|------|--------------|
| 形状 | 正方形、圆形、三角形、圆环、四边形 |

## 功能特性

- **AI 视觉识别**：串口（DMA + IDLE 中断）与 AI 模组通信，按颜色/形状下发检测指令，解析目标坐标并排序（从左到右、从上到下）；
- **二轴云台定位**：X/Y 轴步进电机独立控制，带加减速曲线；TIM 编码器接口实时反馈角度（V2.1.0 新增），支持机械限位与软件电子限位；
- **激光指示**：继电器控制激光笔通断，指向目标坐标，投射画面时自动关闭以免干扰识别；
- **红外遥控**：GPIO 软件模拟 NEC 协议（38kHz 载波），一键暂停/恢复电视，支持 PPTV、CHIGO 两种电视型号（宏切换）；
- **语音播报**：串口语音模块，20 种检测结果及系统提示共 30 余条播报；
- **双屏显示**：迪文串口屏（UART5 + MAX485 半双工 485）显示运行状态、检测计数、多页日志；板载 320×240 SPI LCD 显示主菜单、运行页、日志页；
- **物体日志**：记录每次检测的时间（DS1302 RTC）、模式、颜色、形状、坐标，LCD 分页展示；
- **多运行模式**：停止 / 静态 / 慢速 / 快速 / 手动 / 跟踪 6 种状态机模式，可随时切换；
- **PID 跟踪**：位置式 PID 配合编码器反馈，云台自动跟踪运动目标（跟踪模式）；
- **示波器模式**：ADC + DMA + TIM8 触发 800kHz 采样，CMSIS-DSP FFT 计算频率与峰峰值，LCD 实时绘制波形（开机 C 键进入）；
- **系统测试模式**：开机 D 键进入，逐一验证各外设并打印按键功能提示。

## 软件架构

裸机**前后台架构**（主循环 + 1ms 定时中断），配合**函数指针状态机**组织业务逻辑。

### 主循环流程

```
初始化（HAL / 外设 / 云台回零 / 模式初始化）
        │
        ▼
┌─── while(1) ─────────────────────────────┐
│  Logic_Touch_Key()     触摸按键逻辑      │
│  Logic_Lcd_Page()      LCD 菜单页面管理   │
│  if(1ms 标志)                            │
│      Run_Mode_Now->mode_run()  运行当前模式│
│  run_time 秒计数 → 迪文屏显示             │
│  停止模式下：迪文屏翻页 + LCD 日志翻页      │
└──────────────────────────────────────────┘
```

### SysTick 1ms 中断任务

- `Touch_Key_Scan()`：触摸按键扫描
- `Matrix_Key_Scan()`：矩阵键盘扫描
- `Tripod_Key_Scan()`：云台电子限位检测
- `Voice_Busy_Scan()`：语音模块忙检测
- `run_time` 系统运行计时（非停止模式累加）
- LED0 翻转（500ms 呼吸灯，指示后台正常运行）

### 状态机设计

状态机通过函数指针表实现，每种模式注册 `mode_enter / mode_run / mode_exit` 三个回调：

```c
typedef struct _Mode_Struct
{
    void (*mode_enter)(void);  // 进入模式
    void (*mode_run)(void);    // 模式运行（主循环 1ms 调用）
    void (*mode_exit)(void);   // 退出模式
} Mode_Struct;
```

默认进入停止模式（`Run_Mode_Stop`），按 F1~F4 切换模式，E 键退出至停止模式。

### 云台运动控制

- 步进电机由定时器中断驱动：每次更新中断翻转 STEP 引脚输出一个脉冲，`step_num` 递减控制总步数；
- **加减速控制**：运动前段逐步提速、后段逐步减速（通过动态修改定时器预分频实现）；
- **坐标换算**：目标像素坐标 → 反三角换算为云台角度（`atan2`，`DIS_X=976` 对应云台到屏幕距离 50cm）→ 角度乘以每度步数得到步进数（X 轴每度 59.5 步、Y 轴每度 60 步）；Y 轴角度按 X 轴当前位置做旋转补偿；
- **编码器反馈**（跟踪模式）：TIM1/TIM4 编码器实时读取云台角度，作为 PID 闭环反馈。

### 中断服务

| 中断 | 处理内容 |
|------|----------|
| SysTick | 1ms 时基，按键/限位/语音扫描 |
| TIM2 / TIM3 | 云台 X/Y 轴步进脉冲输出与加减速 |
| USART1 | AI 模组数据接收（DMA + IDLE 帧检测） |
| UART5 | 迪文屏触摸返回数据（逐字节中断接收 + 空闲帧检测） |
| ADC + DMA | 示波器模式 1024 点采样完成标志 |

## 运行模式

| 模式 | 进入方式 | 说明 |
|------|----------|------|
| 停止模式 | 开机默认 / 任意模式按 E | 暂停检测，可翻页浏览日志 |
| 静态模式 | 菜单页按 F1 | 检测静态图片（电视画面）上的目标，画面坐标连续 5 次稳定后定位 |
| 慢速模式 | 菜单页按 F2 | 低速传送带：检测到目标 → 红外暂停电视 → 连续 20 次确认 → 逐点指示 → 恢复播放 |
| 快速模式 | 菜单页按 F3 | 高速传送带，逻辑同慢速模式，采用更快的确认节奏 |
| 手动模式 | 菜单页按 F4 | 手动输入目标坐标（像素或距离 cm 两种模式），方向键微调 |
| 跟踪模式 | 触摸键 C 打开跟踪开关后按 F1 | 进入后云台移至画面中心，PID + 编码器闭环自动跟踪目标 |

### 检测流程示例（慢速模式）

```
轮询 AI 模组
   │ 检测到目标
   ▼
红外发送 OK 键 → 暂停电视
   │ 连续 20 次仍检测到目标（3 秒超时则恢复播放重新检测）
   ▼
缓存全部目标坐标（最多 10 个）
   │ 每 5 秒指示一个
   ▼
云台移动至目标 → 打开激光笔 → 语音播报 → 写入日志
   │ 全部指示完毕
   ▼
关闭激光笔 → 红外恢复播放 → 等待下一轮
```

## 开机操作

上电后 2 秒内，通过触摸按键选择进入模式（需连续两次检测到按键，并有蜂鸣提示）：

| 操作 | 进入模式 | 说明 |
|------|----------|------|
| 不按键 | 正常模式 | 完整检测系统（初始化全部外设，云台回零，进入停止模式） |
| 按住 C 键 | 示波器模式 | ADC 800kHz 采样 + FFT，LCD 显示波形、频率、峰峰值 |
| 按住 D 键 | 系统测试模式 | 初始化全部外设，迪文屏打印各按键功能提示 |

**示波器模式操作**：触摸键"上"增大采样周期（时基变慢）、"下"减小采样周期，每次 ±10%。

**系统测试模式按键提示**（迪文屏打印）：

| 按键 | 功能 |
|------|------|
| A | 云台先左右转、再上下转、再复位 |
| B | 播报一条语音 |
| C | 发送一次遥控器"OK"键码 |
| D | 切换一次激光笔亮灭 |
| 左 | 切换一次检测的形状和颜色 |
| — | 每 1 秒打印一次返回的坐标值 |
| 右 | 停止测试 AI 通信、停止打印坐标 |
| 上 | 测试编码器，手动转动云台 |
| X / Y | X：左小右大；Y：下小上大 |
| 触摸屏翻页按键 | LCD 打印键值 |
| 键盘 | LCD 屏打印键值 |
| 下 | 按一次打印一次当前时间 |

## 通信协议

### AI 视觉识别模组（USART1）

**发送检测指令**（8 字节）：

```
5A A5 03 01 <color> <shape> 9F F9
```

- `color`：1=红 2=绿 3=蓝 4=黄
- `shape`：1=正方形 2=圆形 3=三角形 4=圆环 5=四边形

**接收检测结果**：

```
5A A5 <len> <num> [xH xL yH yL] [xH xL yH yL] ...
```

- `num`：检测到目标数量（0~10）
- 每个目标 4 字节：X 坐标（高 8 位在前）+ Y 坐标（高 8 位在前），分辨率 1366×768

### 迪文串口屏（UART5 + MAX485）

**写数据变量**（DGUS 协议）：

```
5A A5 <len> 82 <addrH> <addrL> <data...>
```

- 文本行地址：`0x5000 + 行号 × 0x20`
- 运行状态/计数地址：`0x6000`（运行秒数）、`0x6002`、`0x6004`（慢速识别总数）、`0x6006`（快速识别总数）、`0x6008`、`0x600A`、`0x600C` 等
- 迪文屏触摸"上一页/下一页"按键返回码 `1 / 2`，驱动日志翻页

### 红外遥控（NEC 协议软件模拟）

GPIO 输出 38kHz 载波（26μs 周期翻转），软件延时实现 NEC 码型：

- 引导码：9ms 载波 + 4.5ms 空闲
- 逻辑 0：560μs 载波 + 560μs 空闲
- 逻辑 1：560μs 载波 + 1.96ms 空闲
- 数据帧：用户码 2 字节 + 数据码 + 数据反码

电视型号在 `HardWare/inc/infared.h` 中通过宏切换：

```c
#define PPTV
// #define CHIGO
```

| 型号 | 用户码 | OK/暂停 键数据 |
|------|--------|----------------|
| PPTV | 0xA8 0x1B | 0x14 |
| CHIGO | 0x00 0xFD | 0x08 |

## 注意事项

1. **源码编码**：所有 `.c / .h` 源码注释为 **GBK 编码**，使用 VS Code / Keil 时请选择 GBK 打开，避免中文注释乱码；本说明文件为 UTF-8。
2. **红外遥控**：发射协议按 NEC 标准软件模拟，更换电视型号时修改 `HardWare/inc/infared.h` 中的宏（`PPTV` / `CHIGO`）及对应用户码/键码即可。
3. **传送带方向**：慢速/快速模式的传送带运动方向通过 `run_slow.h` / `run_fast.h` 中的宏定义切换（默认 `*_RIGHT_TO_LEFT`，即物体从右向左运动）。
4. **云台参数**：每度步数（`X_STEP_ANGLE`=59.5 / `Y_STEP_ANGLE`=60）与屏幕映射系数（`DIS_X`，云台到屏幕距离换算）在 `HardWare/inc/tripod.h` 中配置，需与机械结构匹配。
5. **校准时序**：首次上电需等待云台手动校准完成（`manual_claib_finish`），校准通过触摸按键完成。
6. **DS1302 校时**：如需修改系统时间，可在 `Core/Src/main.c` 中取消 `DS1302_WriteTime` 相关注释并填写时间。
7. **逻辑改动提示**：`logic.c` 中旧的矩阵键盘模式切换逻辑（`Logic_Matrix_Key`）已注释，当前模式切换统一走 `Logic_Lcd_Page`（菜单页按键）。
